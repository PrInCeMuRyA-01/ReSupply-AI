# Final submission checklist

## Source

- [ ] The GitHub repository is Public and opens signed out.
- [ ] README, LICENSE, backend, docs and tests are directly at the root.
- [ ] GitHub detects the MIT license.
- [ ] A fresh reviewer can install dependencies, run the app and prepare the demo using the English README.
- [ ] All files needed to run the UI/API are included.
- [ ] No local secrets, passwords, environments, databases or raw recordings are uploaded.
- [ ] `.env.example` is included with placeholders.

## Video

- [ ] The final MP4 is below three minutes; target 2:45.
- [ ] It shows the actual functioning web app.
- [ ] The synthetic data and Sandbox/test-fund labels are visible.
- [ ] AI selection/review, budget, owner approval, hold, capture and receipt are demonstrated.
- [ ] The same order is shown across payment and receiving.
- [ ] Goods arrival is described as simulated.
- [ ] Narration is English or includes an English translation; captions match the final edit.
- [ ] Private credentials entry is removed.
- [ ] The YouTube video is Public, processed and opens signed out.
- [ ] Audio, subtitles and on-screen values are readable.

## Submission

- [ ] English description reflects what the recorded build actually does.
- [ ] The form contains the actual public repository and YouTube URLs.
- [ ] Setup/testing instructions are linked.
- [ ] Listed AI and PayPal tools were actually used.
- [ ] No placeholders, invented accuracy/profit claims or unimplemented sponsor integrations remain.
- [ ] The current official rules have been reviewed before final submission.

References: [official rules](https://paypalaihackathon.devpost.com/rules) and [submission requirements](https://paypalaihackathon.devpost.com/), checked 14 October 2026.
